# Historical documents

These files were the previous contents of `docs/`. They include roadmaps, implementation plans, company explanations, and earlier architecture write-ups.

They are **not** the source of truth for the current code. Several describe Spark, Selenium, Scrapy, safety limits, and download workers as if they were wired into the API. The audited documents in `docs/architecture/` and `docs/api/` are the ones that match the implementation as of this audit.

Use this folder only for historical context.
